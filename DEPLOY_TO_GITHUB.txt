STEP 1: Create GitHub Repository
---------------------------------
1. Open your browser and go to: https://github.com
2. Log in to your GitHub account (or create one if you don't have)
3. Click the "+" icon in the top-right corner
4. Select "New repository"
5. Fill in these details:
   - Repository name: tech-resource-library
   - Description: Full-stack web application for curated tech learning resources with React and FastAPI
   - Visibility: Public (recommended) or Private
   - ⚠️ IMPORTANT: DO NOT check any boxes (no README, no .gitignore, no license)
6. Click "Create repository"

STEP 2: Connect and Push to GitHub
-----------------------------------
After creating the repository, GitHub will show you commands.
Copy YOUR repository URL and run these commands:

In your terminal (PowerShell/Command Prompt), run:

git remote add origin https://github.com/YOUR_USERNAME/tech-resource-library.git
git branch -M main
git push -u origin main

Replace YOUR_USERNAME with your actual GitHub username!

Example:
git remote add origin https://github.com/johndoe/tech-resource-library.git
git branch -M main
git push -u origin main

STEP 3: Verify Deployment
--------------------------
1. Refresh your GitHub repository page
2. You should see all your files
3. README.md will be displayed automatically

========================================
TROUBLESHOOTING:
========================================

If you get "Permission denied" error:
- Use HTTPS URL (not SSH)
- GitHub may ask for username and password
- For password, use Personal Access Token:
  1. Go to GitHub Settings → Developer settings → Personal access tokens
  2. Generate new token (classic)
  3. Select "repo" scope
  4. Copy the token and use it as password

If you get "Repository not found":
- Double-check the repository URL
- Make sure you created the repository on GitHub first
- Verify your username is correct in the URL
